# ARDMX

Descàrregues de la versió actual del projecte **ARDMX** (2026): controladors
**ARDMX One** i **ARDMX EVO**, basats en ESP32, i l'**APP ARDMX** per a Android.

Web del projecte: [lallumdelpessebre.cat](https://lallumdelpessebre.cat/descarregues/)

## Manuals

| Document | Idioma | Versió |
|---|---|---|
| [Manual de l'APP ARDMX](Manuals/Manual_APP_ARDMX_CAT.pdf) | Català | 3.0 |
| [Manual de la APP ARDMX](Manuals/Manual_APP_ARDMX_CAST.pdf) | Castellano | 3.0 |

Els noms dels fitxers no porten el número de versió perquè els enllaços de la web
no canviïn quan s'actualitzin. La versió vigent s'indica en aquesta taula.
